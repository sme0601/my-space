【我的专属空间】 · 离线单文件版本使用说明
======================================================

✅ 你现在拿到的是一个 "完全离线" 的版本：
   • 不需要启动任何命令行
   • 不需要 Node/npm
   • 不需要访问服务器/联网
   • 整个 App 就一个 HTML 文件（460.5 KB，内含全部 JS/CSS/图标）
   • 单文件已内置"自动跳到首页"逻辑，不用手动加 #/dashboard

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
方法一（推荐 · 零出错）· Windows 双击脚本
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1. 直接双击：「【双击启动-Windows】.bat」（或旧名：【双击用Edge打开】.bat）
  2. 会自动用 PowerShell 生成标准 file:// URL
  3. 用 Microsoft Edge 打开 App 并跳到首页「首页总览」
  4. ✅ 本脚本【强制用 Edge，绝不回退系统默认浏览器】
     如果你的电脑默认浏览器被联想浏览器劫持，脚本也会强制调 Edge。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
方法二（彻底根治劫持）· 导入注册表补丁
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1. 右键「【永久设置Edge为HTML默认浏览器】双击导入.reg」→ 合并
  2. 提示框点"是"，然后重启电脑
  3. 以后所有 .html / .htm / http:// / https:// 都会默认用 Edge 打开
  4. 想改回去就双击「【还原HTML默认打开方式】.reg」

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
方法三 · 直接双击 HTML 文件
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1. 双击「我的专属空间.html」即可进入
  2. 如果默认浏览器不是 Edge：右键 HTML → 打开方式 → Microsoft Edge
  3. ✅ 新版本内置了"自动跳到首页"

关于「数据消失」：这是 IndexedDB 浏览器隔离机制，不是 App bug
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Q: 为什么我昨天写的任务/日记今天没了？
  A: 因为你用了不同方式打开（例：昨天 localhost，今天 file://），
     或者换了浏览器（Chrome→Edge）、Windows 账号、开了 Edge 无痕。
     IndexedDB 会把这些当成"不同 App"，各自一份数据。

  💎 正确长期使用方式（只选一个，不要再换）：
     ① 固定 Edge + 双击 bat / 双击 HTML 的 file:// 方式；
     ② 或者固定 Edge + 启动 dev server 的 localhost 方式。

  🛟 保险：每次大改数据后，进入「⚙️ 设置 · 备份」→「💾 导出备份」。
     下载的 JSON 是你全部数据的完整副本。
